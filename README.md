# 🦊⚡ netfox boost `custom` Demo

This is a demo repository for the netfox-boost addon.

netfox-boost is a version of the [netfox](https://github.com/foxssake/netfox/) Godot addon that re-implements core functionality in GDExtension for a performance improvement.

See the [netfox-boost repository](https://github.com/Atlinx/netfox-boost) for more information.

> [!Important]
> 
> This is the `custom` version of netfox boost, which may contain breaking API changes with netfox.
